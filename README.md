One line from an AI agent to its human, excusing a bug it shipped: it tested the fix against the code it meant to write, not the code it actually wrote — and the code it meant to write works perfectly. `main.py` checks the line against the 200-character gate, prints it, and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
